# RUNBOOK — реальный движок на десктопе (Windows)

«Симбионт» сам не содержит логики обхода — он запускает готовые инструменты как
процессы и управляет ими. Режим выбирается **автоматически**:

| Режим | Инструмент | Сервер? | Админ? | Что делает |
|------|-----------|---------|--------|-----------|
| **VPN** | sing-box | да (config.json) | да для TUN; нет для `mixed` | Полный туннель + маршрутизация + ad-block |
| **Обход (прозрачно)** | GoodbyeDPI | нет | **да** (WinDivert) | Ломает DPI на прямом соединении, без VPN |
| **Обход (без админа)** | ByeDPI | нет | **нет** | Локальный прокси с десинхронизацией DPI; приложение само ставит системный прокси |

Логика выбора при нажатии «Подключиться»:
1. есть `config.json` с реальным сервером → **VPN** (sing-box);
2. иначе запущено от администратора → **GoodbyeDPI** (прозрачный обход);
3. иначе → **ByeDPI** (обход без админа через системный прокси).

Движок включается, если найден хотя бы один бинарник. Нет ни одного — приложение
показывает прямое подключение с реальным пингом (никаких выдуманных серверов).

## Установка
```powershell
powershell -ExecutionPolicy Bypass -File tools\setup_windows.ps1
```
Скачает sing-box + GoodbyeDPI + ByeDPI в `%APPDATA%\Symbiont`.

## Обход БЕЗ прав администратора (ByeDPI) — то, что просили
1. Установите движок (выше).
2. Запустите «Симбионт» **обычно** (без админа). Нажмите «Подключиться».
3. Приложение запустит ByeDPI (локальный прокси `127.0.0.1:1080`) и **само пропишет
   системный прокси** в ветке пользователя (без админа), а при отключении вернёт как было.
   - Работает для приложений, уважающих системный прокси (Chrome/Edge и др.).
     Firefox использует свои настройки прокси.
   - Может примениться не мгновенно — иногда нужно несколько секунд или переоткрыть вкладку.
4. **Защита от сбоя:** если приложение аварийно закрылось, не откатив прокси, при
   следующем запуске оно само восстановит прежние настройки (бэкап в
   `%APPDATA%\Symbiont\proxy_backup.json`).
5. **Стратегия сетезависима.** Если сайт не открылся — отредактируйте
   `%APPDATA%\Symbiont\byedpi_args.txt` (по умолчанию `-p 1080 --disorder 1 --auto=torst --tlsrec 1+s`; пробуйте другие
   опции десинхронизации ByeDPI).

## Обход С правами администратора (GoodbyeDPI) — прозрачно
Запустите «Симбионт» **от имени администратора** → обход применится ко всему
трафику без настройки прокси. Стратегия — `%APPDATA%\Symbiont\bypass_args.txt`
(по умолчанию классический набор `-p -r -s -f 2 -k 2 -n -e 2`).

## VPN (свой сервер)
Положите рабочий sing-box-конфиг в `%APPDATA%\Symbiont\config.json`.
- без админа: inbound `mixed` (локальный прокси `127.0.0.1:2080`) + включить системный прокси;
- полный VPN: inbound `tun` + `auto_route: true` + запуск от админа (+ Wintun.dll).
Перед запуском приложение делает `sing-box check` и покажет причину, если конфиг невалиден.

## Диагностика
- **«Движок не установлен»** — нет ни sing-box, ни goodbyedpi, ни ciadpi. Запустите setup.
- **Обход сразу падает (GoodbyeDPI)** — нет прав администратора. Запустите от админа или используйте ByeDPI.
- **ByeDPI запустился, но сайт закрыт** — смените стратегию в `byedpi_args.txt`.
- **После подключения нет интернета в браузере** — системный прокси указывает на наш
  порт; при сбое перезапустите приложение (оно откатит прокси) или выключите прокси в
  Параметрах Windows.
- **VPN: config invalid** — приложение покажет вывод `sing-box check`.

## Что впереди
- Переключатель стратегий обхода прямо в интерфейсе.
- Живые метрики скорости/пинга через туннель (Clash API).
- Автогенерация `config.json` приложением из подписанного манифеста.
- Android (VpnService) и iOS (NetworkExtension) — см. NATIVE_INTEGRATION.md.

## zapret (winws) — лучший обход для РФ (YouTube/Discord), нужен администратор

setup_windows.ps1 скачивает готовый бандл (Flowseal/zapret-discord-youtube) в
`%APPDATA%\Symbiont\zapret\` — там `general.bat` (+ варианты), `bin\winws.exe`, `lists\`.

- Если приложение запущено **от администратора** и папка zapret есть — обход идёт через
  zapret (приоритетнее GoodbyeDPI). winws перехватывает трафик на уровне пакетов
  (WinDivert), поэтому работает для **всех** приложений (Telegram, Discord, браузеры) и
  умеет QUIC (YouTube).
- Запуск от администратора: кнопка **«Перезапустить от администратора»** в приложении
  (UAC), либо ПКМ по `symbiont.exe` → «Запуск от имени администратора».
- Стратегия по умолчанию — `general.bat`. Если какой-то сайт не открывается, попробуйте
  другую: в папке zapret много вариантов `general (ALT…).bat`, `general (FAKE TLS AUTO).bat`
  и т.п. Чтобы выбрать другую, впишите её имя в файл `%APPDATA%\Symbiont\zapret\zapret_bat.txt`
  (например: `general (ALT4).bat`) и переподключитесь.
- При отключении приложение глушит winws (`taskkill /IM winws.exe`).

Обход DPI сетезависим: конкретная рабочая стратегия подбирается опытным путём (так у всех
инструментов). zapret даёт максимальный шанс, но гарантировать вслепую нельзя.
