# Как запустить «Симбионт»

Клиент — на Flutter. Ниже — самый быстрый путь увидеть интерфейс и полный путь с бэкендом.

## 0. Поставить Flutter (один раз)
1. Установи **Flutter SDK** (stable): https://docs.flutter.dev/get-started/install
2. Проверь: `flutter doctor` — он подскажет, чего не хватает для нужной платформы.

## 1. Распаковать и подтянуть зависимости
```bash
unzip symbiont_build.zip
cd symbiont_build
flutter pub get        # подтянет пакеты и ЗАБАНДЛЕННЫЙ шрифт JetBrains Mono
```

## 2. Запустить — выбери платформу

### Самый быстрый взгляд на UI (без тяжёлых тулчейнов): браузер
```bash
flutter run -d chrome
```
Откроется веб-версия. Движок VPN на вебе — заглушка (MockEngine), но **весь интерфейс,
ядро связи, стили и навигация видны** — для оценки дизайна этого достаточно.

### Windows-десктоп (приоритетная цель, реальный движок)
Нужен **Visual Studio 2022** с компонентом «Desktop development with C++».
```bash
flutter run -d windows
```
- Для полноценного VPN/TUN-режима запускай приложение **от имени администратора**
  (иначе обход работает в режиме локального прокси — это нормально, см. подсказку в UI).

### Linux / macOS / Android / iOS
```bash
flutter devices            # список доступных устройств
flutter run -d <id>        # напр. linux / macos / <android-emulator-id>
```
(Linux: нужен `clang/cmake/ninja/gtk` — `flutter doctor` подскажет.)

## 3. (Опционально) Поднять бэкенд — для узлов/манифеста/аккаунта
Без бэкенда приложение работает в режиме честного прямого подключения. Чтобы появились
узлы, подписанный манифест, аккаунт и поддержка — подними бэкенд локально:
```bash
cd backend
pip install -r requirements.txt
uvicorn server:app --host 0.0.0.0 --port 8000
```
Затем в онбординге приложения укажи сервер `http://127.0.0.1:8000` (или собери клиент
с зашитым адресом — см. DEPLOY.md, `--dart-define=SYMBIONT_BASE_URL=...`).

Проверить весь конвейер без VPS (генерация узла → манифест → клиентская логика):
```bash
python3 server/selftest_pipeline.py
python3 server/selftest_controlplane.py
python3 server/selftest_persistence.py
python3 server/selftest_client_logic.py
```

## 4. Что смотреть в интерфейсе
- **Главный экран** — ядро связи (новый сигнатурный герой): нажми, чтобы подключиться;
  состояния отключён/подключение/подключён различаются кольцом + иконкой + текстом, а в
  подключённом показывается активный путь каскада (Прямой/Обход/Туннель/Реле).
- **Кнопка стиля** в шапке — 4 оформления (минимализм/брутализм/киберпанк/симбиоз).
- **Вкладки**: Защита / Узлы / Правила / Анализ / Аккаунт / Поддержка.

## Что уже переработано в этом билде
- Единые токены (8-pt отступы, типошкала 1.25, motion) — ритм и кегли выровнены НА ВСЕХ экранах.
- Общие компоненты (карточки/кнопки/лейблы/поля) на токенах + базовая доступность.
- Навигация: тач-таргеты ≥44, Tooltip/Semantics, выделение активного пункта для скринридеров.
- Сигнатурное «ядро связи» с честным конечным автоматом.
- JetBrains Mono забандлен (цифры/IP одинаковы на всех ОС), поднят контраст подписей.

Полная карта оставшейся переработки — в `DESIGN_INVENTORY.md` (иду по ней экран за экраном).

## Если сборка ругается
- `flutter pub get` сначала; затем `flutter doctor` — закрой пункты с ✗ для своей платформы.
- В коде остался мёртвый класс `_Dial`/`_ArcPainter` (предупреждение анализатора, НЕ ошибка) —
  уберу в следующем заходе.
- Пришли текст ошибки сборки — поправлю точечно (я не могу запускать Flutter в своей среде).
