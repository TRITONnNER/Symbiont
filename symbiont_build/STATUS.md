- Реальный публичный IP, провайдер, страна, ASN (через ip-api.com).
- Реальный пинг (TCP до публичных якорей) и скорость (скачивание ~3 МБ).
- Послойная классификация блокировки по каждому сайту: `ok / DPI-блок (TLS-сброс) / TCP-блок / DNS-блок`.
- Прогрессивный показ + таймауты на каждый этап → **не зависает** (был баг бесконечной загрузки — исправлен).
- Пометка бренда оператора: «PJSC Vimpelcom **(Билайн)**», МТС, МегаФон, Ростелеком, Tele2 и др.
- **Подтверждено скриншотом:** верно определил IP 95.25.181.102, Билайн/AS3216, DPI-блок YouTube/Discord/X, TCP-блок Instagram/Telegram.

## 2. Обход блокировок — движок zapret/winws (лучший для РФ) — 🟡

- При запуске **от администратора** и наличии zapret обход идёт через **winws** (пакетный перехват, WinDivert) — работает для **всех** приложений (Telegram, Discord, браузеры) и умеет QUIC (YouTube).
- **Окно zapret убрано:** winws запускается СКРЫТО (без отдельного окна и логов). Симбионт делает скрытую копию `.bat`, убирает `start /min`, и стартует через PowerShell `-WindowStyle Hidden`.
- Стратегия по умолчанию — `general.bat` (проверенный РФ-набор Flowseal). Переопределяется файлом `%APPDATA%\Symbiont\zapret\zapret_bat.txt`.
- **Почему вслепую не гарантирую:** обход DPI сетезависим у ВСЕХ инструментов; конкретная рабочая стратегия под провайдера подбирается. YouTube(QUIC) — самый тяжёлый случай.

## 3. Автоподбор рабочей стратегии («чтобы само заработало») — 🟡

- Кнопка «Подобрать обход автоматически» перебирает **готовые стратегии zapret** (`general.bat`, `FAKE TLS AUTO`, `ALT2…ALT12`, `SIMPLE FAKE` — ~20 штук), запускает каждую скрыто, перепроверяет твои заблокированные сайты и **оставляет первую рабочую**, сохраняя её.
- **Конфликт устранён:** автоподбор больше НЕ запускает GoodbyeDPI поверх winws (два обхода на одном WinDivert рвали сеть — это была причина «нет интернета»).
- Жёсткие таймауты: движок ≤120 с, UI ≤150 с → **бесконечного подбора больше нет** (был баг — исправлен).
- Проверка стратегии идёт по TLS-доступности хоста; для QUIC-видео это лишь косвенный сигнал.

## 4. Обход без прав администратора — ByeDPI (локальный прокси) — 🟡

- Поднимает SOCKS5-прокси и сам прописывает системный прокси пользователя (без админа), откатывает при отключении (+ восстановление после сбоя).
- **Честное ограничение, показывается в UI:** покрывает только приложения, уважающие системный прокси (Chrome/Edge). **Telegram и Discord (десктоп) системный прокси игнорируют** → им нужен админ (zapret/GoodbyeDPI).

## 5. Запуск от администратора через приложение (не PowerShell) — 🟡

- Манифест с принудительным админ-запуском **сломал сборку** (LNK1327, дубль `requestedExecutionLevel` в линковке Flutter) — **откатан**.
- Рабочий способ: ПКМ по `symbiont.exe` → «Запуск от имени администратора», или один раз Свойства → Совместимость → «Запускать от администратора».
- В приложении есть кнопка «Перезапустить от администратора» (UAC) — показывается, когда обходу нужны права.

## 6. Интерфейс, кликабельность, режимы — ✅ (вслепую — 🟡)

- Кнопка-круг, карточка «Обход блокировок», плитки режимов охвата, кнопка админа — все кликабельны (баг с `const`-виджетами и карточкой без `onTap` — исправлен).

## 7. Бэкенд (аккаунты, ключи, подписанный манифест, поддержка) — ✅

- **Smoke-тест: 14/14 проходят** (единственная часть, реально запускаемая в среде сборки).

## 8. VPN, маршрутизация, game-boost, мульти-узлы, ad-block — 🔴

## Порядок применения (важно — иначе старая версия)

1. Закрой Симбионт; сними процессы: `taskkill /F /IM symbiont.exe /IM winws.exe`.
2. Скопируй из архива `lib` поверх проекта: `Copy-Item -Recurse -Force "...\symbiont_build\lib" "Z:\symbiont_build\"`.
3. Один раз скачай движки: `powershell -ExecutionPolicy Bypass -File tools\setup_windows.ps1` (должно быть `[4/4] OK: zapret`).
4. Собери: `flutter build windows --release`.
5. Запусти `build\windows\x64\runner\Release\symbiont.exe` **от администратора** (ПКМ → «Запуск от имени администратора»).
6. «Анализ» → «Запустить анализ» → при блокировках «Подобрать обход автоматически» (жди до ~2 мин, не виснет).
