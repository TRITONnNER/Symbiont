# Дизайн-система «Симбионт» — направление и токены

Документ фиксирует, **как должно быть у нас** (по итогам доказательного исследования),
и что уже реализовано. Не копируем чужие экраны — берём механику и собираем своё.

## Тезис (наша идентичность)

Обычный VPN — бинарный тумблер «защищён/не защищён». «Симбионт» — **адаптивный
организм связности**: каскад (прямой → обход → туннель → реле), детект «занавеса»,
самоподстройка под сеть. Поэтому наш сигнатурный герой — не кнопка вкл/выкл, а
**живое ядро связи**, которое показывает не только «вкл», но и **каким путём через
каскад установлена связь**. Этого нет у Mullvad/Proton/Nord — у них нет каскада.
Это и есть симбиоз: подстройка под сеть-хозяина.

## Принципы (из исследования → в код)

- **Система констант, а не вкус.** 8-pt grid для spacing, модульная type scale
  Major Third (1.25) от базы 16, единый набор кеглей — ритм не «гуляет».
- **Тёмная база не-чёрная**, elevation через осветление поверхности; акцент мятный
  #34E5B0 (на мятной заливке — ТЁМНЫЙ текст, белый не проходит контраст).
- **Контраст по APCA**, не только WCAG: тело Lc ≥ 75, лейблы ≥ 60. Поэтому подняли
  `muted` (#5C6979 → #6E7B8A).
- **Избыточная сигнализация статуса**: цвет + иконка + текст (8% мужчин — дальтоники).
- **Честный конечный автомат**: во время подключения герой НИКОГДА не «зелёный».
- **Doherty <400мс**: отклик мгновенный; motion 120–400мс, ease-out на вход.
- **60-30-10**: ~60% тёмные поверхности, ~30% нейтральный текст, ~10% мята.

## Токены (реализовано)

`lib/design/tokens.dart`:
- **Sp** (8-pt): 4/8/12/16/24/32/48/64.
- **Rad**: 4/8/12/16/24/full.
- **Dur**: micro 120 / short 200 / medium 300 / long 400 / breath 2600.
- **Ease**: standard (0.2,0,0,1), decelerate (вход), accelerate (выход).
- **TT**: тач-таргеты 44/48, иконки 16/20/24.

`lib/theme.dart`:
- **Tg** — type scale: display 40 / h1 32 / h2 25 / title 20 / bodyL 16 / body 14 /
  label 13 / caption 12, с весами и line-height из исследования.
- Палитра K: подтянут контраст `muted`.

Шрифт: **JetBrains Mono** забандлен (`assets/fonts/`, прописан в pubspec) для цифр/
метрик/IP — одинаков на всех платформах (был системный Consolas → пестрота по ОС).

## Сигнатурный герой (реализовано)

`lib/screens/widgets/connection_core.dart` — **ConnectionCore**:
- конечный автомат: idle / measuring / connecting / connected / blocking / error;
- «дыхание» в connected (масштаб ±1.8%), вращающаяся дуга в connecting/measuring;
- кольцо + иконка + текст меняются вместе (избыточная сигнализация);
- **чип активного пути каскада** (Прямой/Обход/Туннель/Реле) — наша фишка;
- `Semantics(button, toggled, label)` — доступность для скринридеров (было 0);
- подключён на главный экран вместо старого круга.
