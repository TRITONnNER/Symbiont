# Симбионт — UI/UX спецификация и промты для Claude Design

Документ описывает **всё**, что есть в десктоп-сервисе: дизайн-систему, навигацию,
каждый экран/окно/раздел/кнопку и механику за ними. В конце — готовые промты для
Claude Design (десктоп + мобайл + веб). Всё сверено с фактическим кодом (`lib/`),
а не по памяти — это то, что уже реализовано, и его нужно **допиливать, а не рисовать с нуля**.

## 1. Навигационная модель

**Десктоп:** слева вертикальный `_Rail` (иконка + подпись `navd.*`, выбранный = mint),
сверху `_TopBar` (статус-текст + иконки 📖 глоссарий / ❓ FAQ / ⚙ настройки + `_ConnBadge`).
Контент справа. Группы рейла: `rail.group` (заголовок), `rail.foot` (подпись внизу).

**Мобайл:** нижний `_TabBar` (5 вкладок, активная = mint с подписью), та же `_TopBar`.

**Основные экраны** (enum `AppScreen`): `home` · `nodes` · `routes`(=Rules) · `scan` · `account` · `support`.

**Оверлеи** (поверх, `app.openOverlay`, открываются из топбара/аккаунта/настроек):
`settings` · `tariffs` · `devices` · `referral` · `wheel` · `glossary` · `faq` · `logs` · `rules`.

**Вне навигации:** `onboarding` (до входа) и его шаг `recovery` (сохранение кода).

## 2. Поэкранно — всё, что есть

### 2.1 HOME (`HomeScreen`) — главный экран
**Назначение:** одним взглядом — подключён/нет, качество связи, быстрый «Анализ».
- **Герой-кнопка подключения** — большой круглый контрол в центре, «активное ядро»
  с дыханием (`Dur.breath` 2600 мс) когда подключено; mint при on, нейтраль при off.
  Статус-текст: `status.off` / `status.conn`(подключается) / `status.on` / `status.connected`.
- **CTA «Анализ сети»** — карточка `home.analyze` + `home.analyze.sub` → ведёт в Scan.
- **Панель связи** (`conn.title`): живые метрики — `conn.ping` · `conn.loss` · `conn.speed`
  · `conn.jitter` · `conn.uptime` · `conn.proto`. График пинга `graph.ping`.
- **Монитор** (`mon.title`): `mon.speedtest` (кнопка), `mon.testing` (идёт), `mon.loss`, `mon.off`.
- **Выбор пути/режима** (`modes.label`, меню `route.menu` + `route.auto`): авто-каскад
  или ручной путь — `path.direct` · `path.bypass` · `path.tunnel` · `path.relay`.
- **Бейдж** `_ConnBadge`: `online.badge` / `offline.badge`.

### 2.2 NODES (`NodesScreen`) — серверы
**Назначение:** выбрать узел; видеть живые/быстрые.
- **Поиск** `nodes.search`. **Вкладки** `nodes.all` / `nodes.fav` (избранные).
- **Быстрый выбор:** `fastest.t`+`fastest.sub` (быстрейший по пингу), `random.t`+`random.sub`.
- **Карточка узла:** флаг/страна, метрики `metric.ping` · `metric.loss` · `metric.proto`,
  loadPct (нагрузка из autotune/heartbeat), тогл «избранное».
- **Пульс/доступность** (`pulse.title`/`sub`): `pulse.reachable` / `pulse.empty` — отражает
  **само-починку**: мёртвые узлы исчезают, вернувшиеся возвращаются (heartbeat→sweep).
- **Пусто:** `nodes.none.sub` (честно: фейковых узлов нет — пока сервер не появится).

### 2.3 SCAN (`ScanScreen`) — анализатор сети (2ip + спидтест + детектор блокировок)
**Назначение:** показать IP/провайдера/блокировки и подобрать обход.
- **Диагностика** (`diag.title`/`sub`): кнопка `diag.run` → `diag.running` → `diag.again`.
  Результат: `diag.ip` · `diag.isp` (с брендом оператора) · `diag.country` · `diag.as`
  · `diag.ping` · `diag.speed`.
- **Сайты** `diag.sites` — послойная классификация по каждому: ok / DPI-блок / TCP-блок / DNS-блок.
- **Автоподбор обхода** `diag.tune` → `diag.tuning` → `diag.tuned` / `diag.tune_fail`
  («чтобы само заработало» — перебор стратегий zapret/winws).
- **Скан приложений** (`apps.title`/`sub`): `apps.scan` / `apps.rescan` / `apps.scanning`
  — какие приложения требуют обхода.
- **Game boost** (`boost.title`/`sub`): `boost.measure` → `boost.measuring`, до/после
  (`boost.before`/`boost.after`), `boost.apply`, `boost.note`, `boost.nonodes`.

### 2.4 ACCOUNT (`AccountScreen`) — аккаунт
**Назначение:** статус подписки, активация ключей, рефералка, выход.
- **Метка устройства** `account.label` (+ `account.label.hint`), алиас `aka`.
- **Подписка** `account.sub`, оплачено до `account.paid`, бейдж тарифа `plan.free`/`plan.pro`/`plan.trial`.
- **Устройства** `account.devices` → открывает DevicesScreen.
- **Активация ключа** `activate.label` — поле `activate.ph`, кнопка `activate.btn`, успех `activate.ok`.
  → **СЮДА добавить «Проверить ключ»** (game-style чекер: статус valid/used/expired/revoked/invalid
  + что даёт, до активации; backend `vouchers.check()`).
- **Инвайт** `invite.label`/`sub` + `invite.copy`.
- **Восстановление** `recovery.title`/`sub`/`saved` (показ кода один раз).
- **Выход** `logout` (+ `logout.confirm`).

### 2.5 SUPPORT (`SupportScreen`) — поддержка
- Диалог по токену (сообщения user/support), отправка.
- `report` — пожаловаться, `fix` — «Починить интернет» (быстрое действие = автоподбор).

### 2.6 SETTINGS (`SettingsScreen`, оверлей)
- `settings.title`, ссылка на глоссарий `settings.gloss`.
- **DNS** `set.dns.t`/`d` — шифрованный DNS (DoH/DoT).
- **Протокол** `proto.label`: `proto.direct` / `proto.bypass` / `proto.vpn`.
- **Режимы охвата** `modes.label` (полный VPN / прокси-браузеры / браузер).
- **Защита/фильтры** (движок `Protection`, готово в коде — UI добавить): тоглы
  **блокировка рекламы** · **трекеров** · **фишинга** · **Kill-switch** (аварийный стоп: при
  обрыве туннеля рубит весь трафик, чтобы не «утёк» мимо) · шифрованный DNS.
- Промо-блок `style.title`/`sub`. (Десктоп: автозапуск, сворачивание в трей — см. платформа.)

### 2.7 TARIFFS (`TariffsScreen`, оверлей)
- Карточки планов: `plan.free` / `plan.pro` / `plan.trial` (Free / Premium 199₽ / Ultimate 349₽).

- **Баланс активного времени** (`tariffs.balance`, `tariffs.minutesleft`): когда тариф в режиме

- Преимущества: безлимит устройств, полный relay, game-режим.

### 2.8 DEVICES (`DevicesScreen`, оверлей)

### 2.19 КАРТА ТРАФИКА (`traffic.*`) — живые соединения (я её пропустил ранее)
- `traffic.title`. Список активных соединений: host → каким путём идёт (`traffic.direct` /

  (пусто), `traffic.more` (показать ещё). Приватность: видна только длительность/путь, не содержимое.

## 3. Сквозные механики (что должен передавать UI)

1. **Каскад подключения:** direct → обход DPI → туннель (Reality/Hysteria2/SS2022) → relay.
   Авто-режим пробует по порядку; UI показывает текущий путь (`path.*`) и активный протокол.
2. **Активное ядро дышит** (2600 мс) только когда подключено — главный визуальный сигнал «защита идёт».
3. **Само-починка узлов:** список Nodes живой — мёртвые исчезают, вернувшиеся возвращаются
   (это backend heartbeat→sweep; UI просто отражает `enabled` узлы + пульс).
4. **Autotune узла:** узлы приходят уже с лучшими параметрами (SNI/протоколы/loadPct) — UI
   не настраивает это, но показывает loadPct/протоколы корректно.
5. **Ключи-ваучеры:** активация (`activate.*`) + **проверка без активации** (новый чекер,
   статусы valid/already_redeemed/expired/revoked/not_found/invalid; что даёт код).
6. **Приватность:** аккаунт без данных, recovery-код — единственный ключ; UI это объясняет
   (`onb.privacy`, recovery-экран).
7. **Server-driven:** тарифы/экономика/награды/уровни — с сервера; цифры в UI не хардкодить.
