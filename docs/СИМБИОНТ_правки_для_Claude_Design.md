# СИМБИОНТ — полный разбор интерфейса и список правок для Claude Design

> **Назначение.** Это единый документ-промт: в нём весь интерфейс приложения «Симбионт»,
> все найденные ошибки с точными исправлениями (было → стало), дизайн-система, механика
> экранов, колесо, языки и технические заметки. Цель — чтобы в Claude Design можно было
> пройтись по списку и привести макет в порядок, ничего не упустив.

> карта интерфейса (что на каждом экране и какие тексты). Разделы 8–11 — языки, ограничения,
> что доделать, и чек-лист.

## 1. Что за продукт (контекст для дизайна)

«Симбионт» — сервис связи против блокировок: **не тумблер вкл/выкл, а живой каскад**
`прямой → обход DPI → VPN (reality) → реле`. Сам детектит «занавес» (DPI-блокировку) и
выбирает путь. Тон: спокойный, технологичный, «защита, которая думает за тебя».
Платформы: десктоп (Windows/macOS/Linux), мобайл (iOS/Android), веб.

Тарифы: **Free / Premium 199 ₽ / Ultimate 349 ₽**, на платных — **безлимит устройств**.
Экономика серверная (всё приходит с сервера). Активное время списывается только под подключением.

## 4. Оболочка приложения

**Десктоп:** слева **рейл** (212px) с навигацией, справа — топбар + контент.

**Рейл / таб-бар — 6 пунктов** (заголовок · короткий · подпись · иконка):

## 5. ЭКРАНЫ

### 5.1 Онбординг (до входа)
- Лого (∞ в мятном квадрате) + бренд **Симбионт**.
- Заголовок: **«Связь, которая подстраивается»**.
- Подзаголовок: «Не тумблер «вкл/выкл», а живой каскад: прямой → обход → VPN → реле. Детектит занавес и сам выбирает путь.»
- Метка поля: «Токен или ключ доступа». Поле ввода, плейсхолдер `sb_live_…  или  СИМБ-XXXX`.
- Кнопка **«Начать →»** (мятная). Ниже: «Нет аккаунта? **Создать за 30 секунд**».
- Внизу — индикатор каскада 4 точками: **Прямой** (зел.) · **Обход** (янт.) · **VPN** (mint) · **Реле** (фиол.).

### 5.2 Главная (Защита)
Центр — **ConnectionCore** (большое «ядро»): кольцо/пульс, кнопка-ядро (тап = вкл/выкл), иконка состояния, по центру протокол (`REALITY`). Под ним — колонка (max 540px, gap 12).

**Статус-пилюля (в топбаре), по состоянию:**
| Состояние | Текст RU | Цвет | Иконка |
|---|---|---|---|
| connected | **Защищено · VPN** | mint | `gpp_good` |
| blocking | Блокировка | rose | `gpp_maybe` |
| connecting | Подключаюсь… | amber | `sync` |
| measuring | Замеряю сеть… | aqua | `sync` |
| error | Нет сети | rose | `wifi_off` |
| idle | Не защищено | muted | `gpp_bad` |

**Состояние «отключено» (idle):** мятная кнопка **«Подключиться»** + подсказка «Каскад сам подберёт путь: прямой → обход → VPN → реле.»
**Состояние «подключение» (busy):** кнопка «Отмена».
**Состояние «ошибка»:** карточка «Нет связи с узлами» / «Сеть недоступна или провайдер режет все каналы…» + кнопки «Повторить» и «Сменить узел».
**Состояние «подключено» (live):** при блокировке — плашка «Блокировка DPI — ухожу на реле…» / «Блокировка обойдена — связь держится через реле.», и далее панель метрик:
- Три карточки: **ПИНГ** `38 мс` · **ПОТЕРИ** `0 %` · **ПРОТОКОЛ** `reality`.
- Карточка узла: флаг · «Нидерланды» · `ams-03.symbiont.net` · `38 мс` · полоса нагрузки `34%` · `›`.
- **СКОРОСТЬ**: ↓ `18.4` / ↑ `3.2` Мбит (стрелка отдачи — розовая) + спарклайн на всю ширину.
- Тройка: ⏱ `0:14:32` «в сети» · ⇅ `1.33 GB` «трафик» · 🔒 `AES-256` «шифр».
- Кнопки: **«Анализ»** (растянута) и **«Отключиться»** (по содержимому, розовая).

### 5.3 Узлы
- Заголовок «Узлы» + подзаголовок «Выберите сервер — каскад подстроится под сеть автоматически.» + счётчик `8 узлов · 3 региона`.
- Поиск «Поиск по стране или городу…».
- Фильтры-чипы: **Все · Избранные · Низкий пинг · Свободные**.
- Быстрые действия: **«Авто-выбор лучшего»** («по пингу и нагрузке») и **«Случайный узел»** («сменить отпечаток»).
- Индикатор: **«Узлы на связи»** + «само-починка: мёртвые выпадают, ожившие возвращаются» + счётчик.
- **8 узлов** (страна · город · хост · пинг · нагрузка): NL Амстердам `ams-03` 38/34 ⭐ · DE Франкфурт `fra-01` 46/58 ⭐ · FI Хельсинки `hel-02` 31/22 (бейдж **«вернулся»**) · SE Стокгольм `sto-01` 41/67 · FR Париж `par-04` 52/81 · TR Стамбул `ist-02` 69/44 · US Нью-Йорк `nyc-07` 118/39 · JP Токио `tyo-01` 142/93 (бейдж **«вернулся»**).
- Цвет пинга/нагрузки: ≤60/≤75 зелёный, ≤100/≤90 янтарь, иначе красный. Звезда = избранное. Галочка = выбранный.

### 5.4 Маршрутизация
- Табы **Приложения / Сайты**. Поиск «Поиск по приложениям и сайтам…».
- **Действия маршрута (rl):** `Авто` · `Напрямую` · `VPN` · `Обход DPI` · `Ускорение` · `Блок`. Также `Всё через VPN` / `Только из списка`.
- Сводка по правилам: Авто 312 (звезда) · Напрямую 24 · VPN 8 · Обход DPI 5 · Ускорение 2 · Блок 3.
- Сайты (пример): `youtube.com` → обход, `discord.com` → туннель, `gosuslugi.ru` → напрямую, `rutracker.org` → обход, `github.com` → авто.

## 7. КОЛЕСО — точная механика и шансы (бесплатное колесо)

8 секторов, веса суммируются в 1000 (вес = вероятность в десятых %). **Каждый спин что-то даёт.**

| Сектор | Награда | Шанс |
|---|---|---|
| +15 мин | активное время | 30.0% |
| +30 мин | активное время | 25.0% |
| +1 ч | активное время | 18.0% |
| +2 ч | активное время | 12.0% |
| +4 ч | активное время | 8.0% |
| +8 ч | активное время | 4.0% |
| +1 день | подписка | 2.4% |
| ✦ +7 дней (джекпот) | подписка | 0.6% |

- **Provably-fair (commit-reveal):** заранее публикуется `commitment = SHA256(seed)`; результат =
  `HMAC(seed, "аккаунт:дата") mod 1000 → веса`; после эпохи seed раскрывается → любой пересчитывает и сверяет.
- **Серия:** день 3 → +2 ч, день 7 → +2 дня; пропуск дня сбрасывает.
- **Pity:** 25 спинов без дня → следующий гарантированно даёт день.
- **Золотое колесо (Premium/Ultimate):** те же механики, веса смещены к крупному (шанс «дня+» ≈ ×4).
- *(в макете веса и лейблы уже совпадают с этой таблицей — менять не нужно.)*

## 9. Технические заметки и ограничения (важно)

- Файлы Claude Design используют **встроенный рантайм** (`./support.js`) и **3 его компонента**:
  **`ConnectionCore`** (ядро подключения), **`ListRow`** (строка списка), **`Picker`** (выпадающий выбор).
  Их кода нет в выгрузке — поэтому файл **рендерится только внутри Claude Design**; «голым» в браузере
  показывает сырые `{{ }}`. Правки текстов делать **в исходнике для Claude Design**, проверять — в Claude Design.
- **Не подключать внешние CDN при экспорте под РФ:** шрифты грузятся с `fonts.googleapis.com`, флаги — с
  `flagcdn.com`, фавиконы — с `google.com/s2/favicons`. В России это блокируемо. Для standalone-сборки —
  заменить на системные шрифты и инлайн-флаги; внутри Claude Design можно оставить как есть.
- **Иконки** — Material Symbols (имена вроде `power_settings_new`, `hub`, `casino`, `healing`, `redeem`).
