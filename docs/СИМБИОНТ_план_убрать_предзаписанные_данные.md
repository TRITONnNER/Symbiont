# Симбионт — план: убрать все предзаписанные данные (и всё остальное)

Единый чек-лист доделок по итогам сквозного аудита пяти слоёв (сайт+web, бэкенд+control-plane,
`app/`-оболочка, webapp+платформы, Flutter+Go). Это **план исполнения**, не отчёт: каждый пункт
сформулирован как задача с файлом:строкой, действием и сложностью (🟢 мелочь / 🟡 средне / 🔴 крупно).

Порядок работы согласован: **всё сразу, по слоям**, коммитить послойно.

## 0. Корень проблемы (читать первым)

Пользователь видит не «честный» Flutter-UI (`lib/screens/*`, где метрики реально измеряются через
`Probe`), а **WebShell** — веб-оболочку `webapp/Симбионт.dc.html` в WebView. Она включена по умолчанию
(`lib/main.dart:24`, `kUseWebShell = true`) и общается с движком напрямую через `SymEngineChannel`,
**минуя `AppState`**. Отсюда три следствия, которые и порождают почти всю фабрикацию:

1. Реальные измерения `AppState` (`directPingMs`, `monLossPct`, `speedtestMbps`, `pingHistory`) в
   основной UI **не попадают** — для WebShell это мёртвый код.
2. Движок не считает и не пробрасывает `ping/loss/protocol/stage/down/up`
   (`lib/webshell/sym_engine_channel.dart:110–111`), поэтому оболочка рисует статические дефолты.
3. В `Симбионт.dc.html` **два слоя хардкода**: фолбэки в `app-config.js`/`SYM_DATA` (by design,
   заменяются бэкендом) **и второй слой литералов прямо в render** (экран «Анализ», журнал, счётчики
   трафика), который читает не из конфига → **не обновится даже при подключённом бэкенде**.

> **Принцип, сводящий всё воедино:** всё, что может быть реальным — читать из реального источника
> (движок/бэкенд); всё, для чего источника ещё нет — показывать **честное пустое состояние**
> («нет данных» / «сеть ещё не развёрнута»), а не фейковые демо-данные. Образец честного пустого
> состояния уже есть на странице «Поддержка» (`s_nodesPending`) и в «Правовом» (пустые журналы).

Файлы WebShell дублируются в собираемую копию `symbiont_build/assets/webapp/Симбионт.dc.html`
(синхронизация — `symbiont_build/tools/sync_webapp.py`). **Любая правка `webapp/*` требует ре-синка.**
