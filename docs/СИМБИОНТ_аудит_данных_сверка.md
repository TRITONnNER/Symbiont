## 0. Противоречия из аудита — решаются кодом

### 0.1. Названия тарифов → канон **Free / Premium / Ultimate** 🔧
Источник правды — `DEFAULT_ECONOMY["tiers"]` (`server.py:477–484`) и `docs/PRICING.md`:
**три** тира: `free / premium / ultimate`. Локализация на «Ценах» уже верная:
**Бесплатный / Премиум / Максимум**.

**Правка:** везде, где встречается «Стандарт»/«Команда» (тизер на Главной, Аккаунт,
`acs.plan:'Symbiont Standard'`, строки модалки `mProD/mTeamD/mProPrice/mTeamPrice`),
заменить на **Премиум / Максимум**. «Pro/Team» из строк модалки — туда же.

### 0.2. Реферальные «840 ₽ выплаты» → противоречат коду, заменить на дни 🔧
Вся экономика — **только время**. В коде нет ни одной денежной выплаты рефералам:
- реф-награды в **днях** (`referral`, `server.py:491–494`);
- лимиты репутации — это `payout_cap_month` в **днях** (`server.py:496–501`);
- колесо — призы только дни, без вывода в деньги (`server.py:505–512`).

**Правка:** в карточке рефералов Аккаунта убрать `840 ₽`, показывать начисленные **дни**
(напр. «+N дн начислено»). Заодно копирайт инвайта `inviteS:'…+30 gün Standard'` неточен:
реф-грант **асимметричный** (пригласившему +30, приглашённому +10 за Premium-месяц), а не «+30 обоим».
