# Симбионт — фирменные данные: бренд, домены, почты, соцсети, контакты

Единый «источник правды» по всему, что нужно завести для проекта: имя и тексты, домены, почтовые
ящики, аккаунты во всех соцсетях с готовыми био, контакты поддержки, листинги для сторов и
операционные данные для конфигов.

> **Как пользоваться.** Всё ниже — **предложения**. Хендлы/домены/почты **проверьте на доступность и
> зарегистрируйте** (слово «symbiont» популярно — точные варианты могут быть заняты, поэтому даны
> запасные). **Секреты (токены, пароли) здесь НЕ придумываются** — генерируйте сами (см. §11),
> в репозиторий не коммитьте (`secrets.json`, `*.key`, `.env` уже в `.gitignore`).

## 1. Имя и тексты

| Поле | Значение |
|---|---|
| **Название** | Симбионт (рус.) · **Symbiont** (лат.) |
| **Произношение** | «сим-би-о́нт» |
| **Категория** | сервис связности против блокировок (VPN + обход DPI + ускорение) |
| **Домен-якорь** | `symbiont.app` (уже в коде: `help@symbiont.app`) |
| **Хендл-якорь** | `@symbiont_app` (везде одинаково) |

**Слоганы (RU):**
- «Связь, которая находит путь»
- «Ядро связи, а не тумблер»
- «Всегда на связи — каким угодно путём»
- «Интернет, который не сдаётся»

**Слоганы (EN):** «Connectivity that finds a way» · «The connection core, not a switch» ·
«Always connected — by any route».

**Одна строка (RU):** Симбионт — сервис связности против блокировок: сам находит путь через каскад
**прямое → обход DPI → VPN → реле** и показывает, чем именно вы защищены.

**Короткое описание (для сторов/соцсетей, RU):** Обход блокировок без возни. Симбионт сам подбирает
путь — прямое соединение, пробой DPI, VPN или реле — и держит связь, когда сеть «душит» трафик.
Без email, с кодом восстановления вместо пароля.

**Короткое описание (EN):** Symbiont keeps you online when the network fights back. It picks the
route for you — direct, DPI-bypass, VPN or relay — and shows which path is protecting you. No email,
a recovery code instead of a password.

**Ключевые слова:** обход блокировок, VPN, DPI, Reality, Hysteria2, антицензура, связность, kill-switch,
без логов, recovery-код · censorship circumvention, anti-DPI, VLESS, WireGuard, privacy.

## 2. Голос бренда

- **Спокойно и честно.** Не обещаем «100% анонимности». Говорим, что реально работает и где границы.
- **Не «вкл/выкл», а «каким путём».** Ключевая идея — адаптивное ядро связи и видимый каскад.
- **Приватность как факт, не лозунг.** «Без email», «код не отправлялся», «трафик — только путь».
- **Технически, но по-человечески.** Термины — когда нужно; для пользователя — простыми словами.
- Эмодзи — минимально; тон — уверенный, без хайпа и капса.

## 11. Секреты — генерируйте сами (НЕ из этого файла)

Реальные значения задаются на сервере через окружение/`secrets.json` и **никогда не коммитятся**.
Сгенерировать:

```bash
# Админ-токен панели (владелец)
openssl rand -base64 32
# Секрет регистрации узлов (SYMBIONT_NODE_SECRET) — им узлы подписывают саморегистрацию
openssl rand -hex 32
# Секрет вебхука платежей / алиасов — по одному на каждый
openssl rand -hex 32
```

Задать на бэкенде (systemd env или `secrets.json`), см. `docs/RUNBOOK_MVP.md`:
`SYMBIONT_ADMIN_TOKEN`, `SYMBIONT_NODE_SECRET`, `SYMBIONT_PAY_WEBHOOK_SECRET`, `SYMBIONT_ALIAS_SECRET`,
`SYMBIONT_CORS_ORIGINS`, `SYMBIONT_PAY_PROVIDER`.
