# Симбионт — расширение-компаньон (MV3)

Быстрый доступ из браузера: статус защиты, список узлов (живьём из бэкенда),
переключение и ссылки на полноценный портал/правила. Сам VPN-движок работает в
приложении Симбионт; расширение управляет им через native-messaging.

Компактный попап намеренно лёгкий (окно расширения маленькое), но выдержан в
дизайне Симбионта (палитра, mint-акцент, моно-цифры). Полный UI — это портал
(`web-portal/`) и приложение (`flutter-host/`).

## Сборка и загрузка

```bash
bash build.sh                 # вшивает мост + флаги из webapp/, генерит иконки
# затем: chrome://extensions → «Режим разработчика» → «Загрузить распакованное»
#        указать этот каталог
```

`build.sh` создаёт `vendor/` (мост `symbiont-bridge.js` + флаги стран) — он не в
гите, регенерируется из `webapp/`, чтобы код не разъезжался.

## Настройка

`config.js`:
- `apiBase` — адрес бэкенда (`/v1/*`), он же в `SYM_CONFIG` для моста;
- `nativeHost` — имя native-messaging хоста приложения (`com.symbiont.host`);
- `portalUrl` — куда ведёт «Открыть портал».

## Управление движком (native messaging)

```
попап ──chrome.runtime──▶ background.js ──connectNative──▶ host.py ──HTTP──▶ приложение(loopback)
```

- `nativehost/host.py` — хост протокола native messaging; шлёт команды
  (`connect`/`disconnect`/`status`) на локальный контрол приложения
  (`http://127.0.0.1:8611/control` по умолчанию, см. `SYMBIONT_CONTROL`).
- `nativehost/com.symbiont.host.json` — манифест хоста. Перед установкой замените
  `REPLACE_WITH_EXTENSION_ID` на ID расширения из `chrome://extensions` и
  положите файл в каталог native-messaging хостов ОС (см. док. Chrome), либо
  установщик приложения делает это сам.

Если хоста/приложения нет — попап всё равно показывает узлы и статус (из
бэкенда), а подключение вернёт «приложение недоступно».

## Файлы

| Файл | Роль |
|------|------|
| `manifest.json` | MV3-манифест (popup, service worker, nativeMessaging) |
| `config.js` | адреса бэкенда/портала/хоста + `SYM_CONFIG` |
| `popup.html` / `popup.js` | компактный компаньон-UI (данные через `SYM_API`) |
| `background.js` | мост попап ↔ native-хост |
| `nativehost/` | native-messaging хост (`host.py`, манифест) |
| `make_icons.py` | генерит иконки (mint-∞), без зависимостей |
| `build.sh` | вшивает мост+флаги, генерит иконки |
