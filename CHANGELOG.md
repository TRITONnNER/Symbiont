## v0.1.0 — 19–20 июля 2026

Крупный сквозной этап с двумя целями:

1. **Сделать сервис полностью реальным.** Убрать из всех слоёв (клиент Flutter,
   бэкенд FastAPI, сайт, веб-оболочка, панель) любые предзаписанные / выдуманные
   данные. Всё, что показывается пользователю, приходит с **единственного боевого
   сервера `193.23.219.118`** (манифест узлов, экономика, аккаунт, ключи) либо от
   реального движка на устройстве — иначе показываются честные пустые состояния и `—`.
2. **Собрать и опубликовать все запланированные платформы.** Windows, Linux, macOS,
   Android, iOS (без подписи), расширение браузера — в едином CI-workflow с
   прикреплением ассетов к релизу.

### Бэкенд (FastAPI)

- Боевой режим отдаёт **только реальные узлы** из манифеста, демо-узлы убраны;
  безопасные значения по умолчанию. `637111a`
- Тот же адрес отдаёт лендинг и **реальный чекер ключа** (`POST /v1/key/check`),
  добавлен CORS. `05ceaf1`, `ec66df3`, `cdce9ff`
- Сервер отдаёт **реальные сайт + приложение + панель** (не заглушку `web/`). `d1901c2`
- Жизненный цикл оплаты (webhook + статус) и леджер аккаунта. `a53dce9`
- Всё состояние перенесено на реальную SQLite-БД (WAL); защита `spend_minutes`
  от отрицательного ввода. `f9e3a94`, `ff4495f`
- Аудит-фиксы: 9 багов бэкенда + сквозное логирование. `4f1357c`

### Клиент (Flutter)

### Веб-оболочка (`webapp/`) и сайт (`site/`) — убраны предзаписанные данные

- **Узлы**: показываются только реальные из манифеста, выдуманные демо-узлы удалены

- **Статус подключения честный**: браузер без движка больше не рисует
  «Защищено · VPN · 38 мс» — показывает «работает в приложении». `168b3f2`
- **Экран «Анализ»**: `—` вместо выдуманных IP / handshake / ping / гео. `755b2c7`
- **Журнал событий**: реальные события движка вместо выдуманных 10:01–10:05. `4bc4a49`
- **Аккаунт / Маршрутизация**: честные данные вместо предзаписанных; каталог
  сервисов и списки приложений/процессов больше не выдумываются. `2dfd08f`,
  `c52d094`, `e7a13ea`
- **Поддержка / оплата / превью-аккаунт**: без выдуманной переписки, дат и
  токенов (приветствие бота — единственное сообщение по умолчанию). `b6a19c6`
- **«Колесо удачи»**: серия спинов из реальных данных, а не выдуманные 4/13. `e4386a5`

- **Версия в подвале** — реальная версия манифеста, а не выдуманные

### CI и сборка всех платформ (`.github/workflows/release.yml`)

- Единый workflow **на все 6 платформ**: Windows / Linux / macOS (реальный VPN,
  вложенный sing-box), Android (устанавливаемый APK), iOS (без подписи),
  расширение браузера. Каждая платформа прикрепляет ассет к релизу. `9de5c78`
- **Фикс: весь workflow не компилировался** — непроэкранированные `${{ }}` внутри
  flow-мапы `env: { … }` невалидны в YAML (читались как вложенная карта → 0 job,
  мгновенный fail). Переведено на блочный стиль. `5e6b52c`
- **Android**: плагин `flutter_inappwebview_android` хардкодит
  `getDefaultProguardFile('proguard-android.txt')`, который новый AGP отвергает
  (внутри `-dontoptimize`). Патчим кэш плагина на `-optimize`. `0b076f0`
- **macOS**: stable 3.44 роняет AOT-снапшот на `_window_macos.dart` (мульти-окно,
  `exit -6`) → пин macOS-джобы на Flutter **3.32.0**; затем всплыл деплой-таргет
  пода `flutter_inappwebview_macos` (нужен macOS 10.14+) → поднят прямо в podspec
  до **10.15**. `0b076f0`, `1db9050`, `66f12c7`
- **Windows-фиксы**: `/D_SILENCE_EXPERIMENTAL_COROUTINE_DEPRECATION_WARNINGS` для
  `flutter_inappwebview_windows` на новом MSVC; проброс `GITHUB_TOKEN` в шаг
  докладки движков (иначе запросы к GitHub API давали 401). `2207941`, `e6195b1`
- Релиз **v0.1.0** публикуется workflow-ом (прямой push тега из CI-окружения не
  проходит через прокси). `70b2431`, `d234f5c`
- Убран временный триггер сборки по ветке; workflow запускается по тегу `vX.Y.Z`
  или вручную (`workflow_dispatch` → дописывает в v0.1.0). `6e32a79`

### Известные ограничения

- **Мобильный туннель** (Android/iOS) требует нативной части
  (`VpnService` / `NetworkExtension` + libbox) — пока движок мобильной сборки
  заглушка (Mock): приложение ставится и работает с реальным аккаунтом/узлами/
  оплатой, но сам туннель включится после нативной реализации.
- **iOS**: собирается без подписи (для разработчика); установка на устройство
  требует Apple-сертификатов.
- Настоящий туннель уже работает на **десктопе** (Windows / Linux / macOS).
